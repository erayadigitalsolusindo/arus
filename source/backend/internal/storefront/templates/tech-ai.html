Bedah CSS

Semua animasi di halaman ini murni CSS

Tanpa JavaScript, tanpa gambar. Setiap kartu menampilkan animasi hidupnya beserta kodenya. Buka editor template, cari nama class-nya di tab CSS, lalu ubah angkanya.

1 · Teks gradien bergerak

Gradien diperlebar 200% lalu digeser terus; teks dipakai sebagai "cetakan" (class ai-shine).

Halo, AI
.teks {
  background: linear-gradient(100deg, cyan, violet, cyan);
  background-size: 200% auto;
  background-clip: text;
  color: transparent;
  animation: shine 6s linear infinite;
}
@keyframes shine { to { background-position: 200% center; } }

2 · Mengetik

Lebar dianimasikan dari 0 dengan steps() = jumlah huruf, jadi muncul per huruf, bukan mulus (ai-loop-type).

hello_world()
.ketik {
  width: 13ch;            /* 13 huruf */
  overflow: hidden;
  white-space: nowrap;
  border-right: 2px solid cyan;
  animation: ketik 4s steps(13) infinite alternate;
}
@keyframes ketik { from { width: 0; } }

3 · Denyut & riak (ping)

Pseudo-elemen ::after membesar sambil memudar. Cocok untuk indikator "live" (ai-live).

.titik { position: relative; }
.titik::after {
  content: "";
  position: absolute; inset: 0;
  border-radius: 50%;
  background: inherit;
  animation: ping 1.6s ease-out infinite;
}
@keyframes ping { to { transform: scale(3); opacity: 0; } }

4 · Melayang

Naik-turun dengan translateY pada 50% keyframe. Memakai transform agar halus dan ringan (ai-float).

.melayang { animation: melayang 4s ease-in-out infinite; }
@keyframes melayang {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-14px); }
}

5 · Kartu terangkat saat hover

Bukan keyframes, cukup transition: browser menganimasikan perubahan nilai saat kursor datang (ai-lift).

Arahkan kursor ke sini
.kartu {
  transition: transform .3s, box-shadow .3s;
}
.kartu:hover {
  transform: translateY(-6px);
  box-shadow: 0 24px 44px -24px cyan;
}

6 · Border berputar

Lapisan conic-gradient yang diputar di belakang kotak berpadding 1px, jadi hanya tepinya yang terlihat (ai-spinborder).

neon border
.bingkai { position: relative; overflow: hidden; padding: 1px; }
.bingkai::before {
  content: ""; position: absolute; inset: -60%;
  background: conic-gradient(transparent 65%, cyan, violet);
  animation: putar 4s linear infinite;
}
@keyframes putar { to { transform: rotate(360deg); } }

7 · Marquee tanpa henti

Gandakan isinya, lalu geser tepat -50%: ujungnya menyambung sehingga tampak tak berujung (ai-track).

PYTHONGOLANGREDISKAFKAPYTHONGOLANGREDISKAFKA
.jalur {
  display: flex; width: max-content; gap: 3rem;
  animation: geser 36s linear infinite;
}
.jalur:hover { animation-play-state: paused; }
@keyframes geser { to { transform: translateX(-50%); } }

8 · Loader berputar

Lingkaran dengan satu sisi berwarna, diputar linear tanpa henti. Dasar semua spinner (ai-spinner).

.muter {
  width: 2.6rem; height: 2.6rem; border-radius: 50%;
  border: 3px solid #334155;
  border-top-color: cyan;
  animation: putar .9s linear infinite;
}

9 · Muncul saat di-scroll

Seluruh kartu di halaman ini memakainya: animasi dikendalikan posisi scroll lewat animation-timeline: view(). Coba scroll naik-turun.

.muncul { animation: naik .9s both; }
@supports (animation-timeline: view()) {
  .muncul {
    animation: naik linear both;
    animation-timeline: view();
    animation-range: entry 5% cover 28%;
  }
}
@keyframes naik { from { opacity: 0; transform: translateY(28px); } }

10 · Ramah gerak berkurang

Sebagian orang pusing melihat animasi. Satu aturan ini mematikan semuanya bila pengguna memintanya di sistem operasi. Wajib ada.

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation: none !important;
    transition: none !important;
  }
}

FAQ

Pertanyaan yang sering diajukan

Apakah data kami aman saat dipakai melatih AI?

Data diproses di lingkungan terisolasi, dienkripsi saat disimpan dan dikirim, dan tidak dipakai melatih model pihak lain. Kami bisa menyiapkan model yang berjalan penuh di server Anda sendiri.

Berapa lama sampai ada hasil yang bisa dicoba?

Prototype biasanya siap dalam 2 minggu setelah data awal diterima, sehingga Anda bisa menilai manfaatnya sebelum berinvestasi lebih jauh.

Apakah perlu tim IT sendiri?

Tidak wajib. Kami menyediakan paket pemeliharaan; bila Anda punya tim, kami sertakan dokumentasi dan pelatihan serah-terima.

Bisakah terhubung ke sistem yang sudah ada?

Bisa. Kami mengintegrasikan lewat API, database, atau berkas, termasuk aplikasi kasir dan ERP yang Anda pakai sekarang.

# AGENTS.md — mobile (Flutter, ARUS Mobile)

> Berlaku untuk `source/mobile/` (paket `arus_mobile`, Android). Aturan global ada di `/AGENTS.md`; toolchain dan cara menjalankan di `docs/DEV-ENV.md`.

- **Satu aplikasi, banyak modul.** `lib/core/` (api, session, theme, widget bersama) · `lib/features/<modul>/` (auth, pos; opname/mutasi menyusul) · `lib/shell/` (beranda/menu). Modul tidak saling impor; yang dipakai bersama pindah ke `core/`. Menu beranda disaring dari `Profile.permissions` (sama seperti web); server tetap yang menegakkan izin.
- **Cakupan v1 (keputusan pengguna 2026-10-10):** seluruh fitur kasir web kecuali retur penjualan. **Printer: Bluetooth** (jenis Classic/BLE dan merek/model belum diketahui). Struk ESC/POS ditulis ulang di Dart.
- **Stack:** Riverpod (state), go_router, dio, `decimal` (uang/qty — jangan `double`; API mengirim string desimal), flutter_secure_storage (refresh token), gen-l10n.
- **Teks UI:** dilarang menulis teks langsung di widget. Tambah kunci di `lib/l10n/app_id.arb` (sumber + fallback) dan `app_en.arb`, lalu `flutter gen-l10n`. Kode galat API (`ApiError.code`) diterjemahkan di `ApiError.message(l)`.
- **Server yang menghitung.** Harga/total/pajak dari `POST /sales/quote`; klien hanya menampilkan. Transaksi memakai `Idempotency-Key` yang sama saat retry.
- **Auth native:** header `X-Client: mobile` → refresh token dikirim/diterima lewat badan JSON (bukan cookie) pada `/auth/login|refresh|logout|switch-outlet`. Access token hanya di memori; refresh token di Keystore dan dirotasi tiap refresh. `ApiClient` melakukan refresh single-flight dan mengulang permintaan pada 401 `TOKEN_EXPIRED`. Pencabutan per perangkat belum ada (Fase 10.1).
- **Alamat API:** bawaan = produksi `https://arus-api.erayadigital.co.id` (`AppConfig.productionUrl`); dialog server di login punya pilihan Produksi/Emulator + ketik alamat lain (tersimpan di perangkat), atau `--dart-define=API_URL=http://<IP-LAN>:8080`. Versi terpasang tampil di login dan panel kasir. Cleartext http hanya di manifest debug; rilis wajib https.
- **Tema:** terang/gelap/ikut sistem (`themeModeProvider`, disimpan di SharedPreferences; tombol `ThemeToggleButton`). Warna lewat `context.pal` (ThemeExtension `AppPalette`), jangan hardcode warna di widget. Latar lautan (`core/widgets/ocean_background.dart`: hiu, gelembung, ikan, ombak; `oceanAnimateProvider` dimatikan di test; diam bila animasi sistem dimatikan) dipakai di login.
- **Kasir (`features/pos`):** `PosPage` (panel info outlet 'MAIN' TERTUTUP bawaan: laci di HP, panel lipat di layar >= 840 px), `ProductPane` (cari + kisi; Enter/pemindai HID → kode persis masuk keranjang), `CartPane` (qty, geser hapus, total dari `POST /sales/quote`, sakelar pajak bawaan mati), `pay_sheet` (split bayar, `Idempotency-Key` dipakai ulang selama isi tak berubah, SHIFT_REQUIRED → dialog buka shift lalu ulang). Kisi barang menampilkan thumbnail (`ItemThumb`, `GET /items/{id}/images/{iid}/file?size=thumb`, cache Riverpod); keranjang kosong beranimasi (`EmptyCart`). Bahasa: `localeProvider` + `LanguageButton` (Ikuti HP/id/en, SharedPreferences). Pindah cabang: `core/outlet/outlet_switcher.dart` (beranda tanpa PIN; dari kasir `pos:true` -> dialog PIN penyetuju bila server menjawab `PIN_REQUIRED`; ganti cabang mengosongkan keranjang dan memuat ulang shift/katalog). Tutup shift (`shift_close_page.dart`: uang fisik per metode, selisih ≠ 0 wajib catatan + PIN penyetuju `shift_close`, `Idempotency-Key` satu per layar, `SHIFT_RECAP_CHANGED` → muat ulang rekap) dan Penjualan hari ini (`sales_today_page.dart`: cari nota, total per metode, detail; hanya baca) dibuka dari sidebar (`OutletPanel`: Penjualan hari ini, Tutup shift, Pindah cabang); AppBar hanya memuat nama usaha (tenant), bahasa, tema. **Scan kamera** (`scan_page.dart`, paket `mobile_scanner`): tombol di kotak cari, tetap terbuka untuk beberapa barang, kode dicari persis lewat `exact`. **Keranjang tersimpan** di SharedPreferences per pengguna+cabang (`pos.cart.<user>.<outlet>`, `CartController.restore/_persist`): hanya barang+qty, total selalu dihitung ulang server; kosong setelah bayar. **Isi nota** dibangun dari `CartState.draft()` (`SaleDraft`: baris + override harga/potongan, pajak, member + tukar poin, potongan nota, biaya lain maks 20, salesman); quote TIDAK membawa PIN, hanya bayar (`draft(forPay: true)`). **Member** (`member_picker.dart`: cari `/members/lookup`, poin & deposit dari quote, tukar poin dibatasi `CartState.redeemCap`); **ubah harga/potongan baris** (`line_adjust_sheet.dart` + `approver_fields.dart`: penyetuju + PIN diperiksa `POST /approvals/check`, PIN hanya di memori); **potongan nota + biaya lain** (`costs_sheet.dart`); **bayar** (`pay_sheet.dart`): deposit hanya bila ada member, biaya metode (tanggungan pelanggan) tampil sebelum konfirmasi, mode **Kredit** (DP boleh kosong, limit/jatuh tempo dari quote, melewati limit minta penyetuju `credit_limit` kecuali sudah ada penyetuju ubah harga), nominal tunai cepat (`quickCashAmounts`), **QRIS EraPay** (metode dari `GET /payments/erapay/config`: baris bayar menampilkan tombol Buat QR → `QrImageView` (paket `qr_flutter`) + polling 3 dtk ke `GET /payments/erapay/charges/{id}`; nota tersimpan otomatis saat lunas, `ref_no` = id charge, tombol bayar mati sampai lunas; API key EraPay dipasang owner di web per tenant, server memeriksa ulang saat simpan). **Nota pending** (`pending_controller.dart`, `pending_sheet.dart`): SharedPreferences `pos.pending.v1.<user>.<outlet>`, maks 20, kedaluwarsa 24 jam, hanya isi nota (snapshot sama dengan keranjang tersimpan; override/PIN/quote tidak ikut), dibuka = tukar tempat dengan keranjang berisi. **Pintasan barang** 16 slot (`shortcuts_strip.dart`, `/pos/shortcuts/`, milik kasir, sinkron server) dan **salesman** (`salesperson_picker.dart`, `/catalog/lookup/salespeople/`). **Filter kategori**: chip di atas kisi (`/catalog/lookup/categories/`, `/items/search?category_id=`; migration 00057). Potongan tingkat nota sengaja TIDAK ada (web juga tidak). **Struk Bluetooth** (`core/printing/`, port `receipt.ts`+`escpos.ts` ke Dart: `receipt_layout.dart` = template, `escpos.dart`, `printer_service.dart` = pengaturan per HP di SharedPreferences + koneksi, `printer_sheet.dart` = UI pilih printer + `PrintReceiptButton`): printer Bluetooth Classic (SPP) yang sudah DIPASANGKAN di Pengaturan Android (paket `print_bluetooth_thermal`; izin "Perangkat di sekitar" = CONNECT+SCAN diminta lewat `isPermissionBluetoothGranted` milik plugin, karena plugin menolak semua panggilan bila salah satu belum diberikan), 58/80 mm, potong, cetak otomatis setelah bayar; tombol Cetak struk di dialog sukses, Cetak ulang di Penjualan hari ini (tercatat via `/sales/{id}/receipt/reprint`). Ubah susunan struk di web DAN Dart sekaligus. Printer BLE-only belum didukung; belum diuji di printer fisik. Belum: kupon, catatan per baris, pilih satuan.
- **Windows:** proyek di drive D: tetapi cache plugin Flutter di C: → `kotlin.incremental=false` di `android/gradle.properties` (tanpa ini build gagal 'Could not close incremental caches').
- **Verifikasi:** `flutter analyze`, `flutter test` (fake HTTP adapter, tanpa server), `flutter build apk --debug`. Jalankan dari `source/mobile/`.
- **Ikon:** dari `assets/images/logo_tanpa_text-no-bg.svg`; buat ulang dengan `flutter test tool/gen_icons_test.dart` (menulis `mipmap-*/ic_launcher*.png`; adaptive di `mipmap-anydpi-v26`).
- **Pembaruan otomatis (`core/update/`):** saat dibuka/dilanjutkan, `UpdateGate` memanggil `GET /public/mobile/apk/info` dan membandingkan field `version` dengan `versionName+versionCode` terpasang (`compareVersions`). Lebih baru → layar wajib "Perbarui sekarang": unduh `/public/mobile/apk` ke cache, cek SHA-256, buka pemasang sistem (`MainActivity.kt` + FileProvider, izin `REQUEST_INSTALL_PACKAGES`). Rilis baru: naikkan `version:` di pubspec, `flutter build apk --release`, unggah di Platform Admin dengan kolom versi **sama** dengan pubspec (mis. `1.0.1+2`). APK baru HARUS ditandatangani kunci yang sama (`android/key.properties`), kalau tidak Android menolak memasangnya.

- **Env backend:** `CORS_ORIGINS` (juga dipakai CSRFGuard), `JWT_SECRET` (wajib, ≥32 karakter), `APP_BASE_URL` (alamat SPA untuk tautan email; wajib https di luar dev), `SMTP_HOST/PORT/USER/PASS/FROM` (kosong di dev = `LogMailer`: isi email termasuk tautan hanya dicatat ke log API; `SMTP_HOST` wajib di produksi), `PLATFORM_SETUP_TOKEN` (≥32 karakter; mengaktifkan `/platform/setup` untuk Platform Admin pertama selama tabel kosong; hapus dari server setelahnya), `TRUST_PROXY` (default false; `true` hanya di belakang reverse proxy tepercaya — mengaktifkan `X-Forwarded-For` untuk IP klien/rate limit).
- **Menjalankan:** API `cd source/backend && go run ./cmd/api` (:8080, `GET /healthz`); web: `.claude/launch.json` config `web` atau `cd source/web && npm run dev` (:5173). Test: `cd source/backend && go test ./...`, `cd source/web && npm run check`.
